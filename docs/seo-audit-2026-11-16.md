# SEO and sitemap audit — November 16, 2026

## Live scope and evidence

Checked all 98 URLs in https://digivated.com/sitemap.xml, 13 additional public/private/error/redirect routes, and 24 further internal link destinations. HTTP checks followed redirects and inspected the original HTML for title, description, canonical, robots directives, H1, and JSON-LD validity. Firecrawl also inspected the homepage and a rendered creator profile.

All 98 sitemap destinations returned HTTP 200 without redirects. Every destination had a title, description, and one H1; existing JSON-LD parsed successfully. All 24 additional internal destinations resolved without HTTP errors. robots.txt advertises the production sitemap. Private account, login, inbox, saved, and notification pages return noindex. An unknown route returns a genuine 404 with noindex. Products/promote redirect to membership, carousels to guides, and paused community to the homepage.

## Confirmed defects and fixes

- Three public creator profiles served the same generic title and canonical `/creator` in their original HTML. Client JavaScript personalized the canonical/title later, while `og:url` remained generic even after rendering. The runtime HTML now uses the existing built profile template, adds the public creator's name/bio, and sets matching canonical, Open Graph URL, title, description, and WebPage JSON-LD before JavaScript. Missing/private/invalid profiles return noindex 404; storage outages return noindex 503 with Retry-After. Responses are not cached. Only public name/bio fields are exposed; private records and authentication data are excluded.
- The linked, indexable Market Scanner at `/invstr` was absent from the sitemap. Added it to the public route list.
- The paused article reader `/resources/read` had no original-HTML noindex directive. Added conditional noindex while article publication is disabled.
- Added notifications to the sitemap's defensive private-route exclusion.

## Verification

Production build passed. Eighteen browser checks passed, including the server-rendered template on desktop/mobile, creator actions, tabs, visibility and overflow. The initial full unit suite passed 312 tests with 13 intentional skips; focused tests also cover the preview API fallback, public/private data separation, invalid IDs, metadata escaping, HEAD/method behavior, and outage handling.

## Limits

This is a technical SEO and crawlability audit, not confirmation of Google indexing, selected canonical URLs, rankings, traffic, backlinks, or Core Web Vitals. Google Search Console and field performance data were not accessed. Link checking covered the inspected pages' public HTML links, not every possible query/filter state or third-party outbound site. Client-rendered discovery/feed content may benefit from further server rendering, but no broad rendering rewrite was introduced.
