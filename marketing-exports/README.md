# Digivated desktop marketing kit

- `digivated-desktop-demo.mp4` — 18-second, 1600×900 silent desktop promo. Four beats: discovery, project submission, feedback, and call to action.
- `digivated-desktop-teaser.mp4` — 9-second silent hook and call to action.
- `01-discover.png` through `04-call-to-action.png` — separate 1600×900 desktop graphics.
- `render_campaign.py` — editable source. Run `python3 marketing-exports/render_campaign.py` from the repository root with Pillow and FFmpeg installed.

The UI panels are stylized product demonstrations, not literal screen recordings. Copy describes existing Digivated features and avoids guaranteed outcomes.

## Product-led revision

- `digivated-product-film.mp4` — 18-second 1280×720 film with actual public desktop page captures, restrained product framing, and a generated ambient soundtrack.
- `digivated-product-short.mp4` — 9.6-second condensed cut.
- `product-film-*.png` — companion stills from the revised film.
- `live-{home,projects,creators}.png` and `render_product_film.py` — source captures and reproducible Python renderer.
